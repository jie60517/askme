# openpyxl 讀 xl/worksheets/*.xml 時,裝了 defusedxml 就用它、沒裝就退回 stdlib 的
# xml.etree.ElementTree.iterparse —— 而 stdlib 那支**展開內部實體時沒有上限**。
# (自動偵測寫在 openpyxl/xml/functions.py:`if DEFUSEDXML is True: from

#
# 沒裝的話,一個 1~2 KB、多疊幾層 <!ENTITY> 的 .xlsx 在 extract_text 裡就能展開成
# 上億個字元、數 GB 記憶體。而 save_uploads 是同步的卻被 async def 呼叫,
# 所以那段時間**整個 uvicorn 的 event loop 是停住的**(所有人的問答串流一起卡),
# 而且 /api/preview 每按一次就重跑一遍。裝上之後這種檔案會馬上被拒絕,
# extract_text 回 None,呼叫端改讓 claude 自己讀原始檔 —— 正常的 .xlsx 不受影響。
